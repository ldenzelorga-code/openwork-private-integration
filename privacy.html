Anwendung: OpenWork Private Integration
Betreiber: Luis Denzel · l.denzelorga@gmail.com
Stand: 23. Oktober 2026

1. Zweck und Umfang

Die Anwendung ist eine ausschließlich private OAuth-2.0-Integration für das persönliche Google-Konto des Betreibers. Sie liest Google-Calendar-Termine, Gmail-Nachrichten (nur lesend) und Google-Tasks, um dem Betreiber lokale Zusammenfassungen und vorbereitende Vorschläge zu erzeugen.

2. Keine Weitergabe, keine Speicherung, keine Analyse

Es werden keine Daten an Dritte weitergegeben, keine Daten auf Servern gespeichert und keine Analyse- oder Tracking-Dienste eingesetzt. Alle Verarbeitungen erfolgen ausschließlich lokal auf dem Computer des Betreibers.

3. Google API Services User Data Policy

Die Nutzung der Google Calendar API, Gmail API und Google Tasks API erfolgt in Übereinstimmung mit der Google API Services User Data Policy, einschließlich der Anforderung „Limited Use“: übertragene Daten werden ausschließlich zur Bereitstellung der vom Betreiber selbst angeforderten Funktionen verwendet, nicht für Werbung, nicht für KI-/ML-Training und nicht zur Weitergabe an Dritte.

4. Zugriffsrechte (Scopes)

  • gmail.readonly — nur lesender Zugriff auf E-Mails
  • calendar.readonly und calendar.events — Lesen von Terminen; Anlegen/Ändern nur nach manueller Freigabe durch den Betreiber
  • tasks — Lesen und Pflegen von Aufgaben

5. Widerruf

Die Berechtigung kann jederzeit unter myaccount.google.com/permissions widerrufen werden.
